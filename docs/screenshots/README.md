# DataFix UI Screenshots

This directory contains visual captures of the DataFix Autonomous Data Quality & Repair application across its six core tabs.

1. `01_upload_and_profile.png` - Tab 1: Dataset Ingestion & Profiling (KPI summary cards, semantic column type inference, disguised null ratios).
2. `02_detected_issues.png` - Tab 2: Detected Issues Explorer (Multi-column issue filters, severity breakdown, evidence inspector).
3. `03_root_cause_diagnosis.png` - Tab 3: Root-Cause Diagnosis (Pattern cluster cards, upstream pipeline recommendations, correlation matrix).
4. `04_cell_diff_viewer.png` - Tab 4: Cell-Level Diff Viewer (Confidence color coding: Green ≥0.85, Amber 0.60–0.85, Red <0.60; live threshold what-if slider; approve/reject controls).
5. `05_validation_and_collateral.png` - Tab 5: Validation & Collateral Damage Assessment (Dual Plotly quality gauge, column health heatmap, key integrity report, collateral damage metrics).
6. `06_export_and_reproducibility.png` - Tab 6: Export & Provenance Verification (Download package with 4 synchronized exports, SHA-256 provenance hashes, bit-level replay verification PASS).
